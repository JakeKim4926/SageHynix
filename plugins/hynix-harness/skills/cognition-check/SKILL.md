# Cognition Check

후속 서술형(문항당 5분, AI·복붙 금지)은 제출물과 작업 기록에서 출제된다. AI가 만든 것을 사람이 설명 못 하면 그것이 인지 부채다.

## 절차
1. **설명 카드 작성** (`docs/COGNITION.md`에 추가, 10줄 이내):
   - 한 줄 요약
   - 데이터 흐름: 입력 파일 → 함수(파일:함수) → 출력
   - 핵심 판단 1~2개와 이유 (D-n)
   - 대표 수치와 의미 (VERIFICATION 출처)
   - 실패 모드: 어떤 입력·상황에서 결과가 틀리나
2. **셀프 퀴즈 3문항** — 답은 쓰지 않는다:
   - Q1 "왜": 왜 이 방법/기준을 택했나 (대안 대비)
   - Q2 "어떻게": 특정 수치/화면 값이 어떤 계산으로 나오나 (코드 위치까지)
   - Q3 "만약": 데이터/요구가 이렇게 바뀌면 무엇이 깨지고 어떻게 대응하나
3. 사용자에게 퀴즈를 보여 주고 **본인 말로 짧게 답해 달라고 요청**한다. 시간이 없으면 건너뛰어도 되지만 건너뛴 사실을 카드에 표시.
4. 사용자 답이 오면 채점: 맞은 점, 틀리거나 빠진 점을 코드·문서 근거로 지적. 정답을 길게 대신 쓰지 않는다 — 빠진 핵심 키워드와 확인할 파일 위치만 준다.
5. 사용자가 이해 못 한 부분이 코드가 불필요하게 복잡해서라면 단순화를 제안한다(이해 못 하는 코드는 제출 리스크).

## 규칙
- 카드는 실제 코드와 일치해야 한다. 코드를 다시 읽고 쓴다(기억으로 쓰지 않기).
- 커밋: `docs(cognition): S2 설명 카드 — 수율 계산 기준`
