# 제출 문서 템플릿 (과제 README의 지정 양식이 있으면 그쪽 우선)

## 계획서
```markdown
# <과제명> 계획서
## 1. 문제 정의 — 누구의 어떤 문제인가 (R-n)
## 2. 성공 기준 — 측정 가능한 기준과 측정 방법
## 3. 접근 방법 — 선택과 이유, 검토한 대안 (docs/research/*)
## 4. 범위 — 하는 것 / 하지 않는 것과 이유
## 5. 위험과 가정 — 틀렸을 때의 대응
```

## 협업 기록
```markdown
# 협업 기록
## 1. 업무 담당자와의 합의
| 시각 | 질문/요청 | 답변 요지 | 반영(R-n / 파일) |
## 2. AI(Codex) 활용 방식
- 역할 분담: 조사(서브에이전트) / 구현 / 검증 / 문서 — 각각 사람이 무엇을 확인했나
- 지시 형식: 6칸 SCRIPT([Role][Context][Task][Rules][Output][Done])로 맥락·제약·완료 기준을 넘김
- 가드레일: AGENTS.md 규칙, 차단 훅(차단 기록: .harness/log/guard.jsonl)
## 3. AI 결과를 고치거나 거절한 사례
| 상황 | AI 제안 | 문제 | 내 판단/수정 | 근거 |
## 4. 검증 흐름 — 무엇을 어떤 명령으로 확인했나 (VERIFICATION 링크)
```

## 결과 보고서
```markdown
# 결과 보고서
## 요약 (3줄): 결론 · 핵심 수치 · 신뢰도
## 결과 — 수치 표 (재현 명령 포함)
## 해석 — 업무 관점에서 무엇을 의미하나
## 검증 — 어떻게 확인했나, 무엇이 미검증인가
## 한계와 다음 단계 — 약점 → 위험/영향 → 다음 검증·개선
## 실행 방법 — 설치, 실행, 포트/경로
```
