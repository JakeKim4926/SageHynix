# 후속 서술형 대비 (제출 모드)

## 질문 8~10개 (유형마다 최소 1개)
| 유형 | 예시 형태 |
|---|---|
| 의도 | "업무 담당자의 요구 X를 어떤 기준으로 해석했나? 다르게 해석하면 무엇이 달라지나?" |
| 판단 | "D-n에서 B 대신 A를 고른 근거는? A의 약점은?" |
| 기술 | "{핵심 수치}는 어떤 계산으로 나오나? 결측과 중복은 어떻게 처리했나?" |
| 검증 | "결과가 맞다는 걸 어떻게 확인했나? 무엇이 미검증인가?" |
| 실패 | "데이터가 N배가 되거나, 설비가 추가되거나, 형식이 바뀌면 무엇이 깨지나?" |
| AI 활용 | "AI 결과를 그대로 쓰지 않고 고친 사례는? 왜?" |
| 개선 | "시간이 더 있었다면 무엇을 먼저 했겠나, 왜?" |

전제가 실제 구현과 다른 질문을 1개 넣는다. 서술형에서 전제 오류를 지적하고 자기 작업을 설명해야 하는 상황에 대비하기 위해서다.

## 답변 골격 (질문마다 3줄, 완성 답안은 쓰지 않는다)
- 핵심 사실(근거 위치)
- 약점이나 위험과 그 영향
- 다음 검증·개선 방안
