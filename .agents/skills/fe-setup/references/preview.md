# 웹 IDE 미리보기

신규 Vite 앱의 기본 계약은 아래와 같다. 기존 프로젝트와 과제 지시가 우선하며, 포트 번호만으로 프레임워크를 판단하지 않는다.

- `host: "0.0.0.0"`, `port: 3000`, `strictPort: true`.
- 포트 충돌 시 프로세스 소유자를 확인한다. 다른 프로세스를 임의 종료하거나 자동으로 다음 포트로 바꾸지 않는다.
- API가 필요하면 브라우저는 `/api/...` 상대 경로를 사용한다. Vite proxy에서 실제 로컬 API 포트로 연결한다. 백엔드의 `/api` 접두사 유무를 확인하고 rewrite를 선택한다.
- 브라우저 코드에 `localhost:8000` 같은 개발 환경 주소를 하드코딩하지 않는다. 개발 프록시는 빌드 산출물에 포함되지 않으므로 정적 배포가 요구되면 별도 API 라우팅도 확인한다.
- 서버 응답 → IDE의 실제 미리보기 → 핵심 API 요청 → 필요 시 HMR 순으로 확인한다. HTTP 200만으로 화면 렌더링을 통과 처리하지 않는다.
- 호스트 차단이면 IDE가 제공한 실제 호스트를 명시적으로 허용한다. allowedHosts 전체 허용으로 해결하지 않는다. HMR 설정은 실제 프록시 오류가 있을 때만 조정한다.
- 실행 터미널·프로세스는 유지하고 실행 명령, 실제 바인딩·포트, 미리보기 주소를 보고한다. 테스트가 시작한 서버만 테스트 종료 시 정리한다.

공식 설정 근거: https://vite.dev/config/server-options
