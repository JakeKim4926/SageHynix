# 문제 유형별 평가 설계

유형은 AC 지표로 정한다. 표에 없는 유형(군집화·최적화·추천·LLM 생성/검색 등)은 SKILL ② 1단계대로 Q-n을 남기고 2~7단계만 적용한다.

| 유형 | 판별 신호(AC) | 분할 | 지표 함정 | baseline | 대표 누수 |
|---|---|---|---|---|---|
| 집계·대시보드 | 합계·비율·추이 | 없음 | 비율의 단순 평균, 분모 누락 | 소표본 손 계산 | 필터 전후 분모 혼동 |
| 분류 | 판정·등급·탐지(라벨 있음) | 층화. 같은 ID가 여러 행이면 그룹 분할 | 불균형에서 accuracy | 다수 클래스 | 타깃에서 파생된 열, 같은 ID가 학습·평가 양쪽에 |
| 회귀 | 수치 예측 | 랜덤. ID 반복이면 그룹 분할 | 규모가 다른 그룹을 섞은 평균 오차 | 평균·중앙값 | 결과 이후에 측정된 값 |
| 이상탐지 | 이상·불량 찾기(라벨 희소·없음) | 시간 순 | 라벨이 드물 때 precision 무시, 라벨 없이 점수만 보고 | 단순 임계값(예: 3σ) | 미래 구간 통계로 정규화 |
| 시계열 예측 | 미래 값 | 반드시 시간 순 | 랜덤 분할로 얻은 점수 | 직전 값·같은 주기 값 | 미래 행을 포함한 lag·rolling |

- 분할: 시간 열이 있고 결과를 미래에 쓰면 시간 순이 기본이다. 랜덤 분할을 쓰면 이유를 decision으로 남긴다.
- 지표: AC 지표 하나만 보지 않는다. 불균형이면 혼동행렬 수치(TP·FP·FN)를 함께 보고한다.
- 전처리(스케일링·결측 대체·인코딩)는 학습 데이터에만 맞추고 평가 데이터에는 적용만 한다.
