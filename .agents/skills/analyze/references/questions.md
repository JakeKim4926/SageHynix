# 데이터 의미 질문

원문·데이터 사전·프로파일로 답할 수 있으면 묻지 않는다. 답할 수 없는 것만 ledger question(Q-n)으로 남기고, 담당자에게는 짧은 질문과 선택지로 보낸다.

## 단위와 키
- 행(또는 파일) 하나는 무엇인가 — 측정 한 번·제품 한 개·묶음 하나·시각 하나
- 키 열은 무엇이고 계층이 있는가(상위 묶음 → 개체 → 부분). 같은 키가 여러 행이면 재측정인가 이력인가
- 여러 파일은 어떤 열로 연결되는가. 연결되지 않는 행은 버리는가

## 값의 의미
- 결측은 미측정·0·해당 없음 중 무엇인가. 열마다 다를 수 있다
- 단위·시간대·통화, 열마다 다른 단위가 섞였는가
- 중복 행은 오류인가 실제로 두 번 일어난 일인가
- 범위 밖 값(음수, 100% 초과)은 오류인가 정상인가

## 타깃과 평가
- 타깃(라벨)은 누가, 언제, 무엇을 보고 정했나 — 예측·판정 시점에 알 수 있는 정보인가
- 이상·불량·성공의 정의와 기준값
- 평가용 데이터가 따로 주어지는가, 결과를 언제(미래 데이터·새 개체) 쓰는가
- 결과로 누가 무엇을 판단하나 — 놓침과 오탐 중 어느 쪽이 더 비싼가

## 부록: 반도체 데이터에 자주 나오는 구조 — 일반 지식(미확인)
정답이 아니라 확인할 질문 후보다. 실제 데이터와 담당자 답으로만 확정한다.
- lot → wafer → die 계층: 어느 수준의 행인가, 수율 분모는 어느 수준인가
- 공정 step·설비(챔버) 순서: 같은 wafer가 여러 설비를 거친 이력인가
- 센서·FDC 값: 측정 시각과 판정 시각의 선후
- 수율·불량률 정의: good/total인가, 재작업을 포함하는가
