# 화면 상태와 상호작용

기능의 실제 흐름에 해당하는 상태만 구현한다.

| 상황 | 필요한 동작 | 확인 예 |
|---|---|---|
| 최초 조회 | 로딩 안내, 실패와 구별 | 지연 응답에서 화면 확인 |
| 결과 없음 | 현재 필터와 빈 결과 안내 | 빈 배열 응답 |
| 정상 0값 | 0을 정상 수치로 표시 | total=0 |
| API 실패 | 이해 가능한 오류, 가능하면 재시도 | 실패 후 재시도 성공 |
| 입력 오류 | 입력 근처 안내, 제출 차단 | 필수값 누락·범위 오류 |
| 실행 중 | 중복 실행 방지 | 연속 클릭 |
| 빠른 조건 변경 | 최신 조건의 결과만 반영 | 두 요청이 역순으로 응답 |

검색 입력을 넣었다면 실제 결과가 바뀌어야 한다. 화면 필터 조건과 다운로드·차트 조건도 맞춘다. 기능 없는 버튼을 완료된 UI처럼 두지 않는다.
데스크톱과 좁은 화면에서 주요 버튼·표·오류 메시지가 가려지지 않는지 확인한다. 표가 넓으면 스크롤 영역을 명시한다. 재조회 중 기존 결과를 유지하면 갱신 중임을 표시한다.
